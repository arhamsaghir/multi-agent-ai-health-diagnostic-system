# Screenshots for Thesis Appendix D

## Required Screenshots

To complete the thesis Appendix D, capture the following screenshots from the running application:

1. **Diagnosis Page** - `screenshots/diagnosis_page.png`
   - Navigate to Diagnosis page with Demo Mode enabled
   - Run a "Chest Pain" scenario
   - Show the full results with severity badge, confidence bars, and recommendations

2. **Vision Page** - `screenshots/vision_page.png`
   - Navigate to Vision page with Demo Mode enabled
   - Load the "Pneumonia Case"
   - Show the confidence bar chart and findings

3. **Chat Page** - `screenshots/chat_page.png`
   - Navigate to Chat page
   - Show a sample conversation (e.g., "What are the symptoms of pneumonia?")

4. **History Page** - `screenshots/history_page.png`
   - Navigate to History page
   - Show saved diagnosis records with filters

5. **PDF Report** - `screenshots/pdf_report.png`
   - Export a diagnosis as PDF
   - Screenshot the opened PDF document

## How to Capture

1. Run `streamlit run frontend/app.py`
2. Open browser to `http://localhost:8501`
3. Navigate to each page and capture screenshots
4. Save as PNG files in this directory
5. Update Appendix D in `docs/thesis.md` to reference these files
